# Every version is pinned. The image must be byte-reproducible: a floating
# version here means the container that gets evaluated is not the container
# that was tested.
#
# torch is taken from the cu128 index because that build carries SASS for
# sm_75 (T4) and sm_86 (A10G) -- the two evaluation GPUs -- as well as sm_120
# for the local Blackwell test card. A cu126 build would not run locally; a
# CUDA 12.0-era build would not cover Blackwell. Verified at build time by
# tools/check_arch.py, which fails the build if sm_75 or sm_86 is absent.
--extra-index-url https://download.pytorch.org/whl/cu128
